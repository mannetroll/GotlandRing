# Gotland Ring — steering settings and more corner sliding

Download **GotlandRing-AWD-Portable.exe** and run it on Windows 11 x64. Unity and .NET are included. This is an unsigned portable preview.

- **F3 → AWD physics** now has the same **Low-speed steering (degrees)** and **High-speed steering (degrees)** controls as Arcade comparison.
- The shared defaults are **42° low speed** and **19° high speed**. Adjust them over **25–55°** and **8–25°**, then **Apply & close** to save for future launches. Changing either angle applies to both modes.
- The wheel-angle limit blends smoothly from the low-speed value at rest to the high-speed value at **234 km/h**. Keyboard, mouse, autopilot and the visible front wheels all use these settings.
- AWD autopilot carries more speed into bends and allows more corner rotation, then strengthens countersteering and eases the pedals to recover. Slides come from the tyre physics. The macOS check reaches **8.5° sideslip**, briefly exceeds rear peak grip and completes the lap in **4:15.28** with the whole car on the asphalt.
- **U** toggles mouse/keyboard steering. Mouse movement controls steering only; **right-click** centres it. **W/Up** accelerates, **S/Down** brakes and **X** reverses.
- **Ctrl+P** toggles autopilot. **Tyre squeal** is off by default and can be enabled in F3 settings.

Keyboard steering is the default on each launch. Pausing, recovery, focus changes and autopilot handover centre mouse steering. **F3** opens handling settings, **F4** switches AWD/arcade and **M** mutes sound.
