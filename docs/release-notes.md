# Gotland Ring v0.3.4

Download **GotlandRing-Portable.exe** for Windows 10/11 x64 or **GotlandRing-macOS-arm64.zip** for Apple Silicon Macs. Both include the game runtime; neither requires Unity or .NET to be installed.

- **Plesse analogue instruments:** live speed, RPM, gear, fuel gauge and trip distance in both cockpits, with an instrument overlay in bonnet and chase views.
- **Rebindable controls:** Escape opens Keyboard help & setup. Change or clear bindings, restore defaults, and save them for future launches. On-screen hints follow your saved keys.
- **Updated menus and HUD:** dark panels, clearer settings and a pause menu with driving dynamics, camera setup and keyboard help.
- **Drone camera:** C cycles cockpit, bonnet, chase and drone views. Adjust drone height and following distance from the pause menu.
- **HUD and captures:** J shows or hides the driving HUD. K saves a Desktop PNG with embedded driving and camera metadata; F2 retains circuit, scenery and replay captures.

**P** toggles autopilot, **F** fullscreen and **H** AWD/arcade handling. **F3** opens dynamics and view/sound settings. **Y** switches cars, **Z** opens the training area, **V** cycles scenery views and **O** opens the reference lap.

The Windows x64 package is built on Fractal and tested on Windows 11. A separate Windows 10 runtime test was not available. See [verification](https://github.com/mannetroll/GotlandRing/blob/v0.3.4/VERIFICATION.md) for the checks and platform limits.

Packages have no Windows publisher signature or Apple Developer ID/notarization. The macOS app is ad-hoc signed. Car assets are for noncommercial use; attribution and track-data notices are included. Source films are not bundled.
